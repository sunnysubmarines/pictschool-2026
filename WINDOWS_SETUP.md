# Инструкция по сборке и запуску проекта (Windows)

Эта инструкция предназначена для участников и кураторов, использующих ноутбуки на базе операционной системы **Windows**. Мы подготовили автоматические скрипты, которые установят все необходимые программы и запустят систему в один клик.

## Шаг 1. Разрешение на выполнение скриптов

По умолчанию Windows может блокировать запуск сторонних PowerShell-скриптов. Чтобы разрешить их выполнение:
1. Нажмите `Win + X` и выберите **Windows PowerShell (администратор)** или **Терминал (Администратор)**.
2. Выполните команду:
   ```powershell
   Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
   ```
   *Нажмите `Y` (Да) или `A` (Да для всех), если система спросит подтверждение.*

## Шаг 2. Установка зависимостей и сборка (`setup.ps1`)

В корне проекта лежит скрипт `setup.ps1`. Он автоматически:
- Скачает и установит **Python 3**, **Java 17 (JDK)** и **Flutter SDK** (используя стандартный пакетный менеджер `winget`).
- Создаст виртуальное окружение для Python и установит библиотеки для AI-агента.
- Скачает зависимости для Backend (через Gradle).
- Скачает пакеты Flutter и соберет веб-версию мобильного приложения.

**Как запустить:**
1. Откройте PowerShell в папке с проектом (можно нажать правой кнопкой мыши по пустому месту в папке и выбрать «Открыть в терминале»).
2. Запустите скрипт:
   ```powershell
   .\setup.ps1
   ```
3. Дождитесь появления зеленой надписи: `[OK] Все компоненты успешно настроены!`.

> **Важно:** Если скрипт установил новые программы (Python, Java или Flutter), вам **обязательно** нужно закрыть текущее окно терминала и открыть новое, чтобы система "увидела" установленные программы. После этого можно запустить `.\setup.ps1` еще раз, чтобы он завершил сборку компонентов проекта.

## Шаг 3. Добавление ключа для нейросети

Чтобы AI-агент мог "думать", ему нужен доступ к нейросети (LLM). 
Скрипт установки уже создал для вас файл `.env` в папке `ai\`.

1. Откройте файл `ai\.env` в любом текстовом редакторе (например, в Блокноте или VS Code).
2. Найдите строку `OPENAI_API_KEY=...` и вставьте туда токен, который вам выдал куратор.
3. Сохраните файл.

## Шаг 4. Запуск всего проекта (`start-all.ps1`)

Вам больше не нужно запускать компоненты по отдельности. Для этого есть скрипт `start-all.ps1`. Он откроет 6 дополнительных окон терминала: для Бэкенда, Симулятора, AI-агента и веб-интерфейсов.

**Как запустить:**
1. В PowerShell в папке с проектом выполните:
   ```powershell
   .\start-all.ps1
   ```
2. Скрипт выведет в консоль список ссылок для работы с проектом:
   - **Backend API (Шпаргалка):** http://127.0.0.1:8080/api/docs
   - **Self-Play UI (Ручное управление):** http://127.0.0.1:5173
   - **AI Visualizer (Просмотр игры):** http://127.0.0.1:5174
   - **Mobile Web (Интерфейс игрока):** http://127.0.0.1:5175

3. Чтобы остановить все эти процессы, просто перейдите в главное окно скрипта `start-all.ps1` и нажмите `Enter` или `Ctrl+C`. Он автоматически закроет все созданные дополнительные окна.

---
### Возможные проблемы
- **Ошибка "winget не найден":** Установите "Установщик приложений" (App Installer) из Microsoft Store. Это стандартный компонент Windows 10/11.
- **Backend не запускается (ошибка Java):** Убедитесь, что `java -version` в терминале выводит версию `17`. Если нет, проверьте системную переменную `JAVA_HOME`.
- **Ошибка "simulation_error" при ходе из UI:** Это значит, что окно Симулятора не запустилось или упало. Проверьте окно PowerShell с названием `Симулятор (Port 5055)`.
