# Калибровка движения ESP32-роботов

Эта инструкция описывает настройку движения физической платформы ESP32 через web UI робота.

Калибровка делается отдельно для каждой ESP32. Если есть два робота, один с ролью `robot`, второй с ролью `agent`, у каждого будет свой IP и свои сохраненные настройки.

## 1. Открыть web UI ESP32

После прошивки откройте Serial Monitor в Arduino IDE на скорости `115200`.

Найдите IP-адрес:

```text
IP address: 10.xxx.xxx.xxx
```

Откройте в браузере:

```text
http://<ESP32_IP>/
```

Например:

```text
http://10.186.137.56/
```

На странице должны быть кнопки `Forward`, `Back`, `Left`, `Right`, `Stop` и поля калибровки.

## 2. Проверить механику

Сначала убедитесь, что робот вообще правильно реагирует на простые команды:

1. `Forward` - оба колеса крутятся вперед.
2. `Back` - оба колеса крутятся назад.
3. `Left` - робот поворачивает влево.
4. `Right` - робот поворачивает вправо.
5. `Stop` - моторы останавливаются.

Если робот не двигается, крутит только одно колесо или колесо крутится не туда, сначала исправьте подключение моторов и драйвера.

Проверьте:

- питание драйвера моторов;
- общий `GND` между ESP32, драйвером и питанием моторов;
- провода `IN1`, `IN2`, `IN3`, `IN4`;
- провода `ENA`, `ENB` / `EN2`;
- подключение энкодеров.

PID и калибровка расстояния не исправят перепутанные провода.

## 3. Настроить скорость

Начните с базового значения:

```text
Speed = 430
```

Если робот не стартует или едет слишком слабо, увеличивайте:

```text
450
480
520
```

Если робот дергается слишком резко, уменьшайте.

На этом этапе не нужно добиваться идеального расстояния. Нужно только, чтобы робот уверенно двигался.

## 4. Оставить PID в базовом состоянии

PID не задает расстояние или угол, но выравнивает левое и правое колесо по энкодерам при движении вперед/назад и при поворотах.

На старте поставьте:

```text
PID Kp = 0.8
PID Ki = 0
PID Kd = 0.2
```

Если робот ведет себя странно и нужно проверить механику без автоматической коррекции, временно можно поставить:

```text
PID Kp = 0
PID Ki = 0
PID Kd = 0
```

Финально PID лучше подстраивать после расстояний и поворотов.

## 5. Настроить Ticks/cm

`Ticks/cm` - главный параметр для перевода импульсов энкодера в сантиметры.

Именно он отвечает за ситуацию вида:

```text
указали 5 см, а робот проехал 50 см
```

Порядок настройки:

1. Поставьте:

```text
Forward distance = 20
Ticks/cm = 2
```

2. Нажмите `Forward`.
3. Измерьте линейкой реальное расстояние.
4. Пересчитайте `Ticks/cm`.

Формула:

```text
новый Ticks/cm = старый Ticks/cm * реальное_расстояние / нужное_расстояние
```

Пример:

```text
нужно было: 20 см
проехал: 50 см
старый Ticks/cm: 2

новый Ticks/cm = 2 * 50 / 20 = 5
```

Если робот проехал больше, чем нужно, `Ticks/cm` надо увеличить.

Если робот проехал меньше, чем нужно, `Ticks/cm` надо уменьшить.

Повторите проверку несколько раз, пока команда `Forward` не будет давать близкое к нужному расстояние.

## 6. Настроить расстояние вперед и назад

После настройки `Ticks/cm` настройте длину одного шага:

```text
Forward distance
Back distance
```

`Forward distance` используется для команды вперед.

`Back distance` используется для команды назад.

Если вперед настроен хорошо, но назад робот едет слишком далеко или слишком мало, меняйте именно `Back distance`, а не `Ticks/cm`.

## 7. Настроить повороты

Повороты настраиваются по энкодерам. Для каждого поворота задается количество тиков, которое оба колеса должны пройти для поворота примерно на 90 градусов.

PID работает и во время поворота: он выравнивает левое и правое колесо по количеству тиков. Поворот считается завершенным, когда оба колеса дошли до цели.

Для левого поворота:

1. Нажмите `Left`.
2. Посмотрите, насколько робот повернулся.
3. Если меньше 90 градусов, увеличьте `Left 90 turn ticks`.
4. Если больше 90 градусов, уменьшите `Left 90 turn ticks`.

Для правого поворота:

1. Нажмите `Right`.
2. Если меньше 90 градусов, увеличьте `Right 90 turn ticks`.
3. Если больше 90 градусов, уменьшите `Right 90 turn ticks`.

Начальное значение обычно:

```text
Left 90 turn ticks = 30
Right 90 turn ticks = 30
```

Подбирайте небольшими шагами:

```text
25
30
35
40
```

Левый и правый поворот могут иметь разные значения. Это нормально: моторы и колеса редко бывают полностью одинаковыми.

## 8. Настроить trim колес

Если робот при движении вперед стабильно уходит влево или вправо, используйте:

```text
Left trim
Right trim
```

`trim` добавляет или убирает PWM у конкретного мотора.

Меняйте маленькими шагами:

```text
10
20
30
```

Пример:

```text
Left trim = 20
Right trim = 0
```

или:

```text
Left trim = 0
Right trim = -20
```

Сначала добейтесь, чтобы робот ехал примерно прямо на короткой дистанции. Потом можно точнее подстроить PID.

## 9. Настроить PID

PID нужен для того, чтобы при движении вперед/назад и при поворотах левое и правое колесо проходили примерно одинаковое количество тиков энкодера.

Он не задает расстояние. Расстояние задают:

```text
Forward distance
Back distance
Ticks/cm
```

PID не задает угол поворота. Угол поворота задают:

```text
Left 90 turn ticks
Right 90 turn ticks
```

Базовые значения:

```text
PID Kp = 0.8
PID Ki = 0
PID Kd = 0.2
```

Как подбирать:

- если робот медленно исправляет уход в сторону, немного увеличьте `Kp`;
- если робот начинает вилять, уменьшите `Kp` или немного увеличьте `Kd`;
- `Ki` лучше оставить `0`, потому что на маленькой платформе он часто добавляет раскачку.

Обычно рабочий диапазон такой:

```text
PID Kp = 0.4 ... 1.5
PID Ki = 0
PID Kd = 0.1 ... 0.5
```

Не начинайте настройку с PID. Правильный порядок:

```text
механика -> скорость -> Ticks/cm -> расстояния -> повороты -> trim -> PID
```

## 10. Проверить цепочки простых команд

После настройки простых движений можно проверить цепочку команд из `movement_layer.c`, например:

```text
Forward -> Left -> Forward
```

Сейчас слой движения намеренно поддерживает только базовые команды:

```text
forward
backward
turn left
turn right
```

Если простые движения откалиброваны, такие цепочки тоже будут работать предсказуемо.

## 11. Проверить сохранение настроек

Все настройки из web UI сохраняются во flash-память ESP32 через `Preferences`.

Чтобы проверить:

1. Измените любое значение, например `Forward distance`.
2. Перезагрузите ESP32.
3. Снова откройте `http://<ESP32_IP>/`.
4. Проверьте, что значение осталось прежним.

Кнопка `Reset calibration` очищает сохраненную калибровку и возвращает значения по умолчанию.

## 12. Как калибровка используется backend и AI Visualizer

Backend, AI Visualizer и AI agent отправляют на ESP32 команды по TCP.

ESP32 принимает команду, разворачивает ее через:

```c
movement_expand_command(...)
```

а затем выполняет низкоуровневые движения:

```text
forward
backward
turn left
turn right
```

Эти низкоуровневые движения используют сохраненную калибровку из web UI.

То есть если вы настроили `Forward distance`, `Ticks/cm`, `Left 90 turn ticks`, `PID Kp` и остальные параметры на странице ESP32, эти же настройки будут использоваться при командах из:

- HTTP-кнопок на странице ESP32;
- `nc` / `ncat`;
- backend;
- AI Visualizer;
- AI agent;
- цепочек простых команд в `movement_layer.c`.

## 13. Быстрый чек-лист

1. Открыть `http://<ESP32_IP>/`.
2. Проверить `Forward`, `Back`, `Left`, `Right`, `Stop`.
3. Настроить `Speed`.
4. Настроить `Ticks/cm` по реальному расстоянию.
5. Настроить `Forward distance`.
6. Настроить `Back distance`.
7. Настроить `Left 90 turn ticks`.
8. Настроить `Right 90 turn ticks`.
9. Настроить `Left trim` / `Right trim`.
10. Подстроить `PID Kp`, `PID Ki`, `PID Kd`.
11. Проверить цепочки простых команд.
12. Перезагрузить ESP32 и убедиться, что настройки сохранились.
13. Проверить движение из backend / AI Visualizer.
